# EarthScape Climate Analytics

Hadoop-based big data platform for the EarthScape Climate Agency (Aptech Big Data eProject).
Ingests satellite, weather-station and sensor data; processes it in batch (MapReduce) and
real time (Kafka); runs ML for anomalies, trends and correlations; serves dashboards and alerts
through a secure web portal.

> Status: setup in progress. See `task.md` for the build plan, `spec.md` for requirements,
